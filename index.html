Free Online JSON Formatter, Validator & Compare Tool

PrettyJSON is a free online JSON tool for developers. Format JSON to make it readable, minify it for compact output, validate its syntax, or compare two JSON documents to find added, removed, and changed values. A character counter also measures characters, words, and lines.

Format, minify, and validate JSON

Paste JSON to format it with readable indentation, minify it into compact JSON, or check whether the input is valid. Copy the result or download it as a JSON file.

Compare two JSON documents

Compare original and modified JSON side by side. PrettyJSON reports changed, added, and missing values by path, while ignoring object key order.

Count characters and words

Count characters, characters without whitespace, words, and lines in pasted or typed text.

Run Java and Python code online

Write Java or Python programs, provide standard input, and run them online. Code and input are sent to Wandbox for execution; do not submit sensitive information.

Frequently asked questions

Is PrettyJSON free to use?

Yes. PrettyJSON is free to use in your browser without creating an account.

Is my JSON uploaded or stored?

JSON formatting and comparison happen in your browser. The Java and Python runner is separate: code and standard input are sent to Wandbox for compilation and execution.

What can I do with PrettyJSON?

You can format, minify, and validate JSON, compare two JSON values, count characters, words, and lines, and run Java and Python programs online.
